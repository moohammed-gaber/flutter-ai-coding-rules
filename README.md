# Flutter AI Coding Rules

**Fix Once. Rule Forever.**

Practical Flutter coding rules learned from reviewing AI-generated code.

The **AI Code Review** series turns recurring review findings into reusable instructions. Each episode explains a concrete issue, the reasoning behind the fix, and a rule you can carry into future work.

## Use these rules

1. Open the rule relevant to your task.
2. Copy its **Copy-ready rule** section into your project's `AGENTS.md`, `rules.md`, or your coding assistant's instruction file.
3. Review generated code against the rule and the behavior your feature requires.

Each rule stands on its own, with examples and context where useful. The rules describe this repository's coding conventions; apply them with an understanding of your project's requirements.

Open an issue or pull request with the recurring problem, a small example, and the behavior you expect. Remove private code and credentials before sharing examples.
